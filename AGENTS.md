# Sovia Avatar Studio

Independent Next.js App Router + TypeScript application. Use Biome and shadcn/ui. Use English for all UI text, documentation, comments, filenames, tests, and commit messages. No Python, old mesh-avatar runtime, rig format, .mavatar compatibility layer or live streaming.

Organize code by domain: features/characters, features/editor, engine, server, components/ui. Character documents use studio.character/v1. Normalized coordinates, explicit assets and motion settings. Validate on every trust boundary.

Keep personal images and all derived files in ignored projects/. Keep scratch data in ignored work/. Never commit or upload personal resources. Ask before sending images to an external service. Preserve existing projects; old projects are not silently converted or overwritten.

Run npm run check, npm run typecheck, npm test, npm run build and npm run e2e. Visually review the application and generated character poses. Report limitations honestly.

English commit messages. Local Git author and committer: ComradeSovia <comrade@sovia.work>. Keep a single fresh initial commit on main. Do not retain previous branches or commit history.
